# Стикмен: Забег — как установить на любое устройство

Игра — одно приложение для всех устройств (PWA): одна и та же сборка ставится на iPhone/iPad, Android, Windows и macOS,
работает без интернета, открывается на весь экран со своей иконкой. Каждое обновление (новый `stickman-run-app-<версия>.zip`)
приходит на все устройства сразу: достаточно залить файлы на тот же адрес — установленные приложения обновятся сами.

## 1. Один раз: выложить файлы в интернет (бесплатно)

Для установки на телефон нужен адрес `https://…`. Бесплатные варианты:
- **GitHub Pages**: репозиторий → залить содержимое архива → Settings → Pages → Branch `main` → получить `https://<имя>.github.io/<репо>/`.
- **Netlify** / **Cloudflare Pages**: перетащить папку с файлами в окно сайта.

## 2. Установка

| Устройство | Как |
|---|---|
| **iPhone / iPad** | Открыть адрес в **Safari** → «Поделиться» → «На экран Домой». |
| **Android** | Открыть адрес в **Chrome** → меню ⋮ → «Установить приложение». |
| **Windows** | Открыть адрес в **Chrome** или **Edge** → значок установки в адресной строке (или меню → «Установить»). Появится в «Пуске». |
| **macOS** | **Chrome**/**Edge**: значок установки в адресной строке. **Safari 17+**: «Файл» → «Добавить в Dock». |

Без интернета на компьютере можно и просто открыть `index.html` из распакованного архива двойным щелчком.

## 3. Обновление

Залить файлы новой версии на тот же адрес. Установленное приложение подхватит новую версию при следующем запуске с интернетом.

## Нативные сборки (по желанию)

Если нужны именно файлы `.exe` / `.dmg` / `.apk` / App Store — понадобятся бесплатные инструменты:
Windows/macOS — Electron или Tauri; Android — Android Studio (+ Bubblewrap для упаковки этого же PWA в `.apk`);
iOS — Mac с Xcode (установка на свой iPhone бесплатна на 7 дней, App Store — платный аккаунт разработчика Apple).
